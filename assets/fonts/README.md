# فونت وزیرمتن

فونت **متغیر** وزیرمتن نسخهٔ ۳۳٫۰۰۳ همراه پکیج است:

```
Vazirmatn-Variable.woff2   ← تمام وزن‌های ۱۰۰ تا ۹۰۰ در یک فایل (۱۰۹ کیلوبایت)
fonts.css                  ← تعریف ‎@font-face‎
OFL.txt                    ← متن مجوز
```

فایل اصلی در بستهٔ رسمی `Vazirmatn[wght].woff2` نام دارد؛ اینجا به
`Vazirmatn-Variable.woff2` تغییر نام داده شده چون `[` و `]` در نشانی‌های CSS و
وب‌سرورها دردسر می‌سازند.

دیزاین سیستم فقط از سه وزن ۴۰۰، ۵۰۰ و ۷۰۰ استفاده می‌کند، ولی چون فونت متغیر
است هر سه از همین یک فایل می‌آیند — یک درخواست به‌جای سه‌تا، و حجم کمتر از مجموع
سه فایل ثابت.

مخزن رسمی: https://github.com/rastikerdar/vazirmatn — مجوز SIL OFL 1.1

## اگر نخواهید این فونت لود شود

`fonts.css` عمداً بیرون از باندل webpack است. بارگذارندهٔ PHP آن را فقط وقتی
enqueue می‌کند که `Vazirmatn-Variable.woff2` واقعاً اینجا باشد. اگر فونت را جای
دیگری (مثلاً در قالب سایت) لود می‌کنید، فایل woff2 را از این پوشه بردارید؛ هیچ
چیز نمی‌شکند و زنجیرهٔ جایگزینِ `--rk-font-family` استفاده می‌شود.
