# نشان برند

```
logo-rahkarnet.svg   نشان راهکارنت — بدون تغییر، همان فایل اصلی
```

## چرا اینجاست و نه در اسپرایت آیکون‌ها

اسپرایت (`src/icons/sprite.svg`) آیکون‌های رابط کاربری است: تک‌رنگ، روی شبکهٔ
۲۴، و رنگشان را از `currentColor` می‌گیرند. نشان برند هیچ‌کدام از این‌ها نیست —
گرادیان دارد، رنگ ثابت دارد و روی شبکهٔ ۲۲۰ است. اگر داخل اسپرایت می‌رفت،
`<Icon />` نمی‌توانست رنگش کند و قاعدهٔ ست به‌هم می‌ریخت.

## گرادیان در برابر قاعدهٔ «بدون گرادیان»

دیزاین سیستم عمداً هیچ گرادیانی در کامپوننت‌ها ندارد. نشان برند از این قاعده
مستثناست — نشان، تصویر ثابت برند است نه عنصر رابط کاربری. گرادیان را داخل
کامپوننت‌ها تکرار نکنید.

## استفاده

در PHP نشانی‌اش داخل `window.rahkarUI.logoUrl` قرار می‌گیرد:

```jsx
<img src={ window.rahkarUI.logoUrl } alt="راهکارنت" width="24" height="24" />
```

فایل `width`/`height` ندارد و فقط `viewBox` دارد، پس هر اندازه‌ای بدهید مقیاس
می‌گیرد. شناسه‌های گرادیان داخلش (`rk-gl` و `rk-gr`) یکتا نیستند؛ اگر نشان را
به‌صورت inline در صفحه بگذارید و بیش از یک‌بار تکرار شود، شناسه‌ها تداخل
می‌کنند — با `<img>` این مشکل پیش نمی‌آید.
